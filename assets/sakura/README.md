# Sakura artwork

Miru's [renderer](../../src/sakura.rs) uses the tree shape and shading from
this [AI-generated reference](reference.png) to draw the Home screen in the
active theme. The falling petals and dot shading follow bas3line's
[Kyoto Dusk](https://ascii.rest/kyoto-dusk/). See the [original source](../kyoto-dusk/source.ts)
and [MIT license](../kyoto-dusk/LICENSE).
